## Fork и clone

В исходный репозиторий у вас нет прав на запись. Поэтому:

1. **Fork** — копия репозитория на ваш аккаунт GitHub.
2. **Clone** своего форка на компьютер.
3. Исправления пушите в свой форк.
4. Сдача — **Pull Request** из вашей ветки в исходный репозиторий.

Аккаунт GitHub — если ещё нет. Git: https://git-scm.com/downloads

### Fork

Откройте ссылку на репозиторий вашего варианта. Справа вверху — **Fork** → **Create fork**.

На странице должны быть ваш логин и подпись **forked from**. Дальше работаете с этим репозиторием.

Если кнопки Fork нет — напишите мне.

### Clone

На странице форка: **Code → HTTPS**. В ссылке должен быть ваш логин.

```text
git clone https://github.com/ваш_логин/имя-репозитория.git
cd имя-репозитория
git remote -v
```

`origin` должен указывать на ваш форк. Если нет — удалите папку и клонируйте заново.

### Ветка

```text
git checkout -b фамилия_ИО_номергруппы
```

Пример: `ivanov_aa_35301`. В `main` не коммитьте.

## Коммит и push

Проверьте `.gitignore`. В нём должны быть строки:

```text
venv/
__pycache__/
*.pyc
```

Если их нет — добавьте. Эти файлы в коммит не входят.

```text
git status
git add main.py .gitignore
git commit -m "Fix bugs"
git push -u origin фамилия_ИО_номергруппы
```

Имя ветки — то, что создали на шаге выше. Если `git push` отвечает `403` / `Permission denied` — вы пушите не в свой форк; смотрите `git remote -v`.

## Pull Request

1. Откройте свой форк на GitHub.
2. **Compare & pull request** или **Pull requests → New pull request**.
3. base: исходный репозиторий, ветка `main`. compare: ваш форк, ваша ветка. Если GitHub сравнивает ветки внутри форка — **compare across forks**.
4. Заголовок: `Иванов А.А., группа 35301, вариант 1`.
5. **Create pull request**.

На этом работа сдана. Merge не нажимайте.

## Если уже клонировали исходный репозиторий

Сделайте fork в браузере, затем в папке проекта:

```text
git remote rename origin upstream
git remote add origin https://github.com/ваш_логин/имя-репозитория.git
git checkout -b фамилия_ИО_номергруппы
git push -u origin фамилия_ИО_номергруппы
```

Дальше — Pull Request.
