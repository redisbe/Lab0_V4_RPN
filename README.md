# Вариант 4. Обратная польская запись

Порядок сдачи — в `ИНСТРУКЦИЯ.md`. Ниже — что должна делать программа.

Обратная польская запись (RPN) — выражение без скобок: оператор стоит **после** операндов. Например, `2 1 +` это `2 + 1`, `2 1 + 3 *` это `(2 + 1) * 3`.

Файл `data.yaml` содержит набор выражений: списки токенов (целые числа, в том числе отрицательные, и операции `+ - * /`).

Вычисление на стеке: число кладётся на стек, операция снимает два операнда (сначала правый, затем левый) и кладёт результат. Деление целочисленное **к нулю**, как в C++/Java: `3 / -4 = 0` (не как `//` в Python).

Для корректного выражения печатаются результат и максимум среди всех промежуточных значений на стеке, включая исходные числа. Ошибки: недостаточно операндов, в конце на стеке не ровно один элемент, деление на ноль.

В самом конце выводится корректное выражение с наибольшим результатом (при равенстве — с меньшим номером).

## Примеры

Вход:

```yaml
cases:
  - ["2", "1", "+", "3", "*"]
  - ["4", "13", "5", "/", "+"]
  - ["3", "-4", "/"]
  - ["2", "3"]
```

Ожидаемый вывод:

```text
|   line | expression   | value   | max_intermediate   | error                    |
|--------|--------------|---------|--------------------|--------------------------|
|      1 | 2 1 + 3 *    | 9       | 9                  |                          |
|      2 | 4 13 5 / +   | 6       | 13                 |                          |
|      3 | 3 -4 /       | 0       | 3                  |                          |
|      4 | 2 3          |         |                    | leftover values on stack |

Best case: 1, value = 9
```

## На что обратить внимание

- Если скрипт падает при запуске — изучаем сообщение об ошибке и traceback.
- Если вывод оказался неправильным — запускаем программу в пошаговом режиме и проверяем стек
- Убедитесь, что для всех строк файла скрипт работает правильно
